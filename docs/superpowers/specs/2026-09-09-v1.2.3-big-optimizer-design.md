## 2. Monitor expansion

New rows (labeled exactly): `CPU temp (avg)`, `CPU hotspot`, `iGPU usage`, `iGPU temp`,
`dGPU usage`, `dGPU temp` + existing CPU/RAM/disk/GPU. dGPU rows use nvidia-smi per-GPU
parse; iGPU usage via GPU engine counters (phys-id mapping, best effort); CPU temp avg =
mean of ACPI thermal zones; CPU hotspot + iGPU temp render dimmed "n/a (needs driver)" —
honest placeholders, footnote under the panel. Overlay gains dGPU rows.

Disk: "Disk view" dropdown — `C:` / `D:` / `Both (separate)` / `Combined` (default Both),
per-logical-disk `LogicalDisk` % Disk Time counters, rows labeled `Disk (C:)`,
`Disk (D:)`; persisted next to the refresh interval.
